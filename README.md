# ניהול מטלות ותקלות בדירת שותפים

מערכת שמנהלת את העבודות בדירת שותפים:
- **תורנות שבועית:** סבב קבוע והוגן של המטלות הקבועות (רצפות, מקלחת, מטבח, זבל, אבק). הסבב מחושב בקוד, בלי AI.
- **פניות חדשות:** שותף כותב בטקסט חופשי מה קרה ("הברז במטבח מטפטף"). ה-AI (Gemini) מסווג את הפנייה: תחום, מי אחראי, דחיפות ומאמץ, ומנסח טקסט קצר. קוד קבוע בודק שהתשובה תקינה, ואז:
  - **באחריות בעל הדירה:** נשמרת טיוטת הודעה מוכנה לשליחה.
  - **באחריות השותפים:** הפנייה משובצת לשותף עם הניקוד הנמוך ביותר החודש, עם תאריך יעד.
  - **לא ברורה:** המערכת מבקשת לנסח אותה מחדש.
- **הודעה לקבוצת הוואטסאפ:** כוללת את התורנות, את ה"משימות המתפרצות" ותזכורת לשלוח הודעות לבעל הדירה.

## הדרך הקלה: האתר בענן
**https://roomates-tasks.streamlit.app** פותחים בדפדפן ומשתמשים, בלי להתקין כלום.

- **מגבלה:** הנתונים באתר זמניים. אם האתר לא בשימוש כמה ימים הוא "נרדם", ובכניסה הבאה לוחצים על כפתור כדי להעיר אותו. אחרי שהוא מתעורר הנתונים מתאפסים. האתר מתאים להדגמה. לשימוש קבוע בדירה מריצים במחשב, לפי ההוראות כאן למטה.

## הפעלה במחשב שלכם (Windows), פעם ראשונה

### 1. להתקין Python
להוריד מ-https://www.python.org/downloads ולהתקין גרסה 3.10 ומעלה.
**חשוב:** במסך הראשון של ההתקנה לסמן ✔ **"Add python.exe to PATH"**.

### 2. להתקין את הממשק
לפתוח חלון PowerShell בתיקיית הפרויקט (בסייר הקבצים: קליק ימני על התיקייה ← "Open in Terminal") ולהריץ:
```
python -m pip install -r requirements.txt
```

### 3. להוציא מפתח Gemini חינמי
1. להיכנס ל-https://aistudio.google.com/apikey עם חשבון Google.
2. ללחוץ **Create API key** ולהעתיק את המפתח.
3. בתיקיית הפרויקט, להעתיק את הקובץ `.env.example` לקובץ חדש בשם `.env`.
4. לפתוח את `.env` ב-Notepad ולהחליף את `paste_your_key_here` במפתח.

המפתח אישי. אסור לשתף את הקובץ `.env` או להגיש אותו.

### 4. לפתוח את המערכת
**לחיצה כפולה על `start_ui.bat`.** הדפדפן ייפתח לבד אחרי כמה שניות, בכתובת http://localhost:8501.
צריך להשאיר את החלון השחור פתוח כל עוד משתמשים במערכת. סוגרים אותו כדי לכבות.

## הפעלה משורת הפקודה (בלי ממשק)

```
python main.py weekly                                  תורנות לשבוע הנוכחי
python main.py requests                                טיפול בכל הפניות החדשות בתיבת הפניות
python main.py requests --inbox test_inputs/run2_mixed.csv --output-dir runs/my_test
python main.py requests --note "הערה ליומן ההרצות"
python evaluate.py                                     בדיקת דיוק מול תשובות צפויות
python -m unittest discover tests -v                   בדיקות אוטומטיות של הקוד
```
- `--output-dir`: הפלט נכתב לתיקייה נפרדת, והנתונים האמיתיים לא משתנים.
- כל הרצה נרשמת ב-`output/run_log.csv`.

## מבנה התיקיות

| נתיב | תוכן |
|---|---|
| `data/` | **קלט:** שותפים (`roommates.csv`), מטלות קבועות (`weekly_chores.csv`), תיבת פניות (`requests_inbox.csv`) |
| `output/` | **פלט בפורמט קבוע:** שיבוץ שבועי, יומן מטלות, הודעות לבעל הדירה, ניקוד, יומן הרצות, יומן תשובות AI, הודעת וואטסאפ |
| `prompts/` | פרומפט המערכת לפי גרסאות, ו-`CHANGELOG.md` עם הסיבות לשינויים |
| `src/` | הקוד: `rotation` (סבב), `assignment` (שיבוץ וניקוד), `validator` (בדיקות תקינות), `ai_classifier` (קריאה ל-Gemini), `pipeline` (חיבור השלבים) |
| `test_inputs/` | קובצי קלט להרצות המתועדות, ותשובות צפויות |
| `runs/` | תוצאות ההרצות המתועדות ובדיקת הדיוק |
| `docs/` | יומן פיתוח (`dev_log.md`) וסיכום ההרצות (`runs.md`) |
| `tests/` | בדיקות אוטומטיות |

כדי לשנות שותפים או מטלות קבועות, עורכים את הקבצים ב-`data/`. אפשר לערוך אותם ב-Excel, ושומרים כ-CSV UTF-8.

## פרטיות ומגבלות
- ל-AI נשלח **רק טקסט הפנייה**: בלי שמות, ניקוד או פרטים אחרים. במסלול החינמי Google עשויה להשתמש בטקסט לשיפור המודלים, ולכן לא כותבים בפנייה מידע אישי.
- במסלול החינמי יש מגבלה על מספר הבקשות בדקה וביום. אם המודל הראשי עמוס, המערכת עוברת אוטומטית למודל גיבוי. פנייה שנכשלה בגלל תקלה טכנית נשלחת שוב בהרצה הבאה.
- כל פנייה מטופלת כמשימה אחת. אם יש שתי בעיות, שולחים שתי פניות נפרדות.
